# Фоновые фото первого блока страниц

Положите сюда фото (jpg/png/webp, от 2000 px по ширине) — оно встанет фоном первого блока с затемнением:

- `default.jpg` — для всех внутренних страниц;
- `<раздел>.jpg` — для конкретного раздела: `leistungen.jpg`, `kosten-finanzierung.jpg`, `ueber-uns.jpg`, `kontakt.jpg`, `erstbegutachtung.jpg`, `blog.jpg`.

Пока файлов нет, блок остаётся с нейтральным светлым фоном. После добавления — `npm run build`.
